# ENGANO demo video

`engano-demo.mp4` (3:04, narrated, captions): a real recording of the running app. A brand manager sets up a workspace and a
rule, a creator drafts and is checked, a reviewer rejects, the creator resubmits and ENGANO clears it, and the manager sees the
overview. It also shows image and website checks. The last card lists what is still missing.

`chapters.json` has the chapter times and the caption text. The build scripts (narration, voice, browser recording, assembly) live
next to the submission files in `submission/round2/build/`, outside this repository.
